# シフト作成ヘルプ（試作）

介護施設（看護師・ヘルパー・SP）のシフト作成を手伝うツールの試作です。
`index.html` をブラウザで開くだけで動きます（インターネット接続は、フォントの読み込みにだけ使います）。

## できること

1. **希望入力（iPad）** … 自分で決めた4けたの番号で、自分の希望休だけを入力。入力済みの人はタイルの色が変わる
2. **希望の集約** … 担当者が全員分と入力状況を確認（番号のリセットも可）
3. **一覧表 / 人ごと / カレンダー** … SPの勤務表を自動で組み、表・個人別・日別で表示
4. **勤務時間** … 回数と時間、前月との累計、非常勤の年間上限の確認

## 注意

- 名前・希望休・勤務条件は**すべて架空のサンプル**です
- 勤務表を自動で組むのはSPだけです（看護師・ヘルパーは固定サンプル）
- 4けたの番号や入力内容はブラウザの中だけで動いていて、保存されません（実運用では保存先が必要）
- 勤務時間は休憩を引いていない拘束時間で、前月の数字・時給・年間の上限は仮の値です
